# Gemma 4 Agent Lab

A reproducible engineering journal for an autonomous Python repair agent.

Submitted v1 and v2 each scored **0.06** on the public leaderboard. Reviewed candidates
are unscored. This repository records code, experiments and failures without claiming
a rank or an improvement that has not been measured.

This is a curated import of existing local work, created on 2026-09-27. Commits document
the import and subsequent repository improvements; they are not backdated development history.

Competition data, weights, credentials and raw traces are intentionally excluded.
See [data boundaries](docs/DATA_POLICY.md) and [contributing](CONTRIBUTING.md).
