# Contributing

Use Python 3.12+. Work on a feature branch and open a focused pull request with a concrete
hypothesis, implementation diff, validation evidence and remaining uncertainty.

Never edit a frozen release in place. Make a new candidate and record its source and hash.
Keep experiment configuration separate from packaging and evaluation repairs. A passing
synthetic test is not a solve-rate result. Distinguish submitted artifacts from candidates.

Do not launch GPU notebooks, submit to Kaggle or change the experimental scope as a side
effect of a documentation or packaging change. Keep the launch default disabled.

See docs/DATA_POLICY.md before staging files. This repository was imported in meaningful
present-day commits, with no invented historical dates or claims of human review.
